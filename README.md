# Plataforma de mensajería para redes ad hoc

Actividad guiada: diseño, implementación y evaluación de mensajería de texto sin Internet ni servidor externo.

**Periodo:** 26 de octubre–6 de diciembre de 2026 (seis semanas).

## Alcance

Identificación, descubrimiento, mensajes individuales, confirmaciones, reintentos, historial local y protección del canal. La conectividad ad hoc y el encaminamiento se configuran con herramientas de red existentes. El protocolo de encaminamiento desde cero, los adjuntos y los grupos quedan fuera del alcance obligatorio.

## Estado

Repositorio inicial de planificación. La aplicación aún no está implementada y la tecnología está por seleccionar en la semana 1. Las instrucciones de instalación y ejecución se completarán al implementar el prototipo.

## Organización

`src/`: aplicación; `tests/`: pruebas; `docs/`: diseño, manuales y evidencias. Cada requisito se cierra cuando sus criterios se verifican y la Issue contiene evidencia.
